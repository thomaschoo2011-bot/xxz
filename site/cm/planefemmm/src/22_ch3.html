3位移模式与形函数：把无穷维压缩成六维

网格划好之后，未知量已经从"每一点的位移"缩减为"每个节点的位移"。但还差关键一步：单元内部那些非节点的点，位移是多少？必须人为假定一个函数形式，这就是位移模式（displacement pattern / assumed displacement field）。本章用三节点三角形单元（CST）把这件事做到底，并回答两个理论问题：这个假定凭什么可以用？加密网格凭什么会收敛？

3.1 位移模式：为什么取完全一次多项式

三角形单元有 3 个节点、每节点 2 个自由度，共 6 个待定量。位移函数里的待定系数必须恰好等于 6 个——多了解不出来，少了无法满足全部节点条件。于是 u、v 各取 3 个系数：

u(x,y) = α1 + α2x + α3y　， v(x,y) = α4 + α5x + α6y (4.11)

问题是：3 个系数的组合方式不止一种，为什么偏偏是 {1, x, y} 而不是 {1, x, x2} 或 {1, x, xy}？答案藏在 Pascal 三角形里。

◎ 几何各向同性：一个具体的反例
假设取 u = α1 + α2x + α3x2（跳过了 y）。 把坐标系绕原点转 90°，x → y，这个位移模式就变成了 α1 + α2y + α3y2——和原来不是同一个函数空间。 于是同一个物理问题，仅仅因为你建模时把坐标轴摆的方向不同，算出的答案就不同。这显然荒谬。 Logan 和 Reddy 的教材都把这一点列为选位移模式的第一条准则。

3.2 从位移模式到形函数：CST 的完整推导

设三角形三个节点按逆时针编号为 i、j、m，坐标为 (xi, yi) 等。把三个节点坐标代入 (4.11) 的第一式：

uiujum = 1xiyi1xjyj1xmym α1α2α3 (4.12)

系数矩阵的行列式恰好是三角形面积的 2 倍：

2A = det 1xiyi1xjyj1xmym = (xjym − xmyj) + (xmyi − xiym) + (xiyj − xjyi) (4.13)
▲ 节点必须逆时针编号
若按顺时针编号，(4.13) 给出 2A < 0。这会让后面 ke = BTDB·tA 中的 A 为负——刚度矩阵变负定，结构"越推越缩"，方程解出的位移方向完全错乱。 商业软件通常会自动纠正并给出 "negative Jacobian" 警告，但手算时务必自己保证逆时针。

求逆并整理（这是纯代数，用 Cramer 法则逐项展开即可），得到形函数表达式：

Ni(x,y) = 12A(ai + bix + ciy) (4.14)
ai = xjym − xmyj　， bi = yj − ym　， ci = xm − xj (4.15)

其余两个只需把下标按 i → j → m → i 轮换即可。于是单元内任意一点的位移写成紧凑的矩阵形式：

u = uv = Ni0Nj0Nm00Ni0Nj0Nm de = N de (4.16)
de = [ ui　vi　uj　vj　um　vm ]T　（6×1 单元节点位移列阵） (4.17)

N 叫形函数矩阵（2×6）。注意它的结构：u 只由各节点的 u 插值、v 只由各节点的 v 插值，两个方向互不串扰——这是位移型单元的通例。

3.3 形函数的三条性质（以及它们各自管什么）

性质数学表述它保证了什么
① Kronecker delta Ni(xj,yj) = δij
（本节点为 1，其余节点为 0）		 节点处插值出的位移正好等于该节点的位移未知量，未知量才有明确的物理意义，边界条件才能直接施加。
② 单位分解 Ni + Nj + Nm ≡ 1
（单元内处处成立）		 能精确表示刚体平动。若三节点 u 都等于 u0，则单元内处处 u = u0ΣN = u0，不产生虚假应变。这是完备性的一半。
③ 边界线性 在边 ij 上，Nm ≡ 0，
Ni、Nj 沿边线性变化		 边上位移只由这条边的两个节点决定，与第三个节点无关。所以相邻单元共享一条边时，两侧算出的位移必然相同——这是协调性的来源。

性质 ③ 值得多说一句：正因为它，网格才可以由形状各异的三角形随意拼接。只要两个单元共用完整的一条边（图 4.3 左），无论它们的第三个节点在哪里、面积差多少，边上的位移场都完全吻合，不会撕裂。

3.4 面积坐标：让三角形的积分变成查表

形函数 Ni 还有一个漂亮的几何解释。在三角形内任取一点 P，连 P 与三个顶点，把三角形分成三块小三角形，面积分别记为 Ai（对着节点 i 的那一块，即 △Pjm）、Aj、Am。则

Li ≡ Ai / A = Ni　，　Li + Lj + Lm = 1 (4.18)

这组量叫面积坐标（area / barycentric coordinates）。用它做单元内的积分，有一条一步到位的公式，第 6 章推导体力等效载荷时会反复用到：

∬A L1a L2b L3c dA = a! b! c!(a + b + c + 2)! · 2A (4.19)

3.5 收敛准则：什么样的单元才"越细越准"

有限元只是一种近似，凭什么相信网格加密时解会趋向真解？经典理论给出两条充分条件，Zienkiewicz 称之为收敛准则：

✓ 准则一：完备性（completeness）——必要条件
单元的位移模式必须能精确表示：
① 全部刚体位移（平面问题：2 个平动 + 1 个转动）——否则单元被整体搬走时会凭空产生应力；
② 全部常应变状态（εx、εy、γxy 各为常数）——因为网格无限加密时，每个单元内的应变必然趋于常数，若连常应变都表示不了，加密也无济于事。
一般地：若微分方程的最高阶导数是 m 阶（弹性力学 m = 1），位移模式必须包含完全 m 次多项式。这正是 3.1 节取 {1, x, y} 的理论依据。

验证 CST 满足准则一。把 (4.11) 的应变算出来：

εx = ∂u/∂x = α2　， εy = ∂v/∂y = α6　， γxy = ∂u/∂y + ∂v/∂x = α3 + α5 (4.20)
  • 刚体平动：α1、α4 任意，其余为零 → 应变全零 ✓
  • 刚体转动：取 α3 = −ω、α5 = +ω，得 u = −ωy、v = ωx，正是绕原点转 ω 的小转动，而 γxy = −ω + ω = 0 ✓
  • 常应变：由 (4.20)，三个应变分量各自是独立常数，可任意指定 ✓

6 个系数正好分给 3 个刚体模式 + 3 个常应变模式，一个不多一个不少。这也解释了单刚为什么秩为 3（第 5.4 节）——6 维位移空间里恰有 3 维不产生应变能。

✓ 准则二：协调性（conformity / compatibility）——充分补足
位移场在单元内部连续（多项式天然满足），且在单元之间的公共边上连续（弹性力学只要求 C0，即位移本身连续，导数可跳）。 由形函数性质 ③，CST 自动满足。
同时满足两条准则的单元称为协调元，其解保证单调收敛。
◎ 不协调元也可能收敛：分片试验
协调性是充分而非必要条件。有些故意放弃协调性以换取精度的单元（如 Wilson 非协调四边形，在 Q4 基础上加两个内部气泡模式补偿弯曲能力）反而更准。 判断这类单元是否收敛，要用 Irons 提出的分片试验（patch test）：给一小片网格施加对应常应变的边界位移，若所有单元都精确复现出该常应变场，则通过。 Bathe 在《Finite Element Procedures》4.4 节把分片试验称为"单元可靠性的最终裁判"，商业软件的单元库全部要经过这一关。

3.6 换个单元，只是换 N：Q4 的形函数

本章后续的推导只用到 N，不关心它具体长什么样。所以换成四节点四边形（Q4）时，框架完全不变，只需在自然坐标 (ξ, η) ∈ [−1,1]2 中写出：

Nk(ξ, η) = ¼ (1 + ξkξ)(1 + ηkη)　，　k = 1…4 (4.21)

容易验证它同样满足三条性质。但它的多项式项是 {1, ξ, η, ξη}——不完全二次式，缺 ξ2 和 η2。后果是 Q4 无法精确表示纯弯曲变形（弯曲时截面应保持直线但产生 x2 型位移），于是弯曲能量被错误地转化为剪切能量，单元显得过硬，这就是剪切自锁（shear locking）。细长单元受弯时尤其严重，工程上用缩减积分或加非协调模式来缓解。

第 10 章的收敛实验会给出 CST 与 Q4 在同一悬臂板问题上的定量对比：在 8×4 网格下，CST 的挠度误差仍有 −17.5%，而 Q4 只有 −4.6%。
