本章是第 3 章《杆件有限元方法》的直接延续：从"天然离散"的杆系走向"必须人为离散"的连续体。 参考课程与教材见 第 11.7 节。
◎ 本章学习目标（学完本章你应当能够……）
  1. 判别一个工程问题应按平面应力还是平面应变处理，并写出相应的弹性矩阵 D，说明两者只差一组材料常数替换；
  2. 构造三节点三角形单元（CST）的位移模式与形函数，用 Pascal 三角形解释为什么必须取完全一次多项式，并检验收敛准则（完备性 + 协调性）；
  3. 由最小势能原理独立推导单元刚度矩阵 ke = ∫BTDB t dA，并从推导过程论证它为什么必然对称、奇异、与单元位置无关；
  4. 实施刚度集成法（"对号入座"）把各单元 6×6 单刚装配成 2n×2n 总刚，并预测总刚的零元分布与带宽；
  5. 推导任意分布载荷的等效节点载荷——包括均布线载荷、均布面载荷、线性/抛物线/静水压等非均布载荷——掌握边积分主公式与面积坐标积分公式，并说明"能量等效"与"静力等效"的区别；
  6. 比较直接缩减法、化 1 置 0 法、乘大数法（罚函数）与主从自由度法四种边界条件施加方式的精度与代价，正确处理非零已知位移与斜支座；
  7. 完成一个平面问题的全流程求解：离散 → 单元分析 → 组装 → 载荷等效 → 施加约束 → 解方程 → 求应力 → 后处理平均 → 平衡校核与收敛性判断。
◎ 讲义说明（本讲义借鉴了哪些讲法）
本讲义以课件《平面问题有限元》为骨架，并在若干关键处采用了国外经典课程的处理方式： 单元刚度矩阵不从直接刚度法而从最小势能原理推出——这是 K.-J. Bathe 在 MIT 2.092 与《Finite Element Procedures》第 4 章的标准路线，好处是同一套推导对任何单元、任何维数都成立； 形函数的三条性质（Kronecker delta、单位分解、边界线性）与收敛准则的对应关系，取自 C. A. Felippa 的 CU Boulder Introduction to Finite Element Methods 第 15、16 章； 等效节点载荷用"虚功相等"定义而非"静力合力相等"，并用 8 节点单元 1/6 : 2/3 : 1/6 这个反直觉结果作为分水岭，取自 Felippa 讲义中"一致节点力"（consistent nodal forces）的处理与 Cook 等《Concepts and Applications》第 4 章； "有限元位移解自下方收敛、结构显得偏刚"的 Rayleigh–Ritz 解释，取自 Bathe《Finite Element Procedures》第 4.3 节（收敛性与单调收敛性质）与 Zienkiewicz & Taylor 对变分近似的一般讨论，见参考文献 [1][4]； Pascal 三角形与几何各向同性的讲法取自 Logan 与 Reddy。全部数值例题均由独立的 Python / NumPy 程序验算，秩、行和、条件数、特征值等中间量在正文中一并给出，读者可逐项复核。
