4几何矩阵 B 与应力矩阵 S

有了位移插值 u = Nde，把它依次代进几何方程和物理方程，就能把应变和应力也用节点位移表示出来。这两步各产生一个矩阵，它们是第 5 章能量推导的直接原料。

4.1 几何矩阵 B：从节点位移到应变

把 (4.16) 代入几何方程 (4.5)：

ε = Lu = L(Nde) = (LN)de ≡ B de (4.22)

B = LN 称为几何矩阵或应变－位移矩阵（strain–displacement matrix），尺寸 3×6。逐项求导：∂Ni/∂x = bi/2A，∂Ni/∂y = ci/2A，于是

B = 12A bi0bj0bm0 0ci0cj0cm cibicjbjcmbm = [ Bi　Bj　Bm ] (4.23)

其中每个 3×2 的子块为

Bi = 12A bi00cicibi (4.24)
✓ 三个立刻能看出来的事实
① B 中不含 x、y：b、c、A 全是由节点坐标算出的常数。所以整个单元内应变处处相同——这就是"常应变单元（Constant Strain Triangle）"名字的由来。
② B 与单元的绝对位置无关：bi = yj − ym 是坐标之差。把整个单元平移到任何地方，B 一模一样。这正是"刚体平动不产生应变"在矩阵层面的体现。
③ B 的量纲是 1/长度：位移除以长度得应变。所以单元越小，B 中的元素越大，ke ∝ BTB·A ∝ 1/L2·L2 = 常数级——单刚的量级不随网格加密而爆炸。

一个手算例：标准直角三角形

取 i(0, 0)、j(1, 0)、m(0, 1)（逆时针）。由 (4.15)：

bi = 0 − 1 = −1，bj = 1 − 0 = 1，bm = 0 − 0 = 0
ci = 0 − 1 = −1，cj = 0 − 0 = 0，cm = 1 − 0 = 1
2A = 1，A = 1/2 (4.25)
B = −101000 0−10001 −1−10110 (4.26)

验算一下：若节点位移取 de = [0, 0, 0.01, 0, 0, 0]T（只有节点 j 沿 x 移动 0.01），则 ε = Bde = [0.01, 0, 0]T。单元底边长 1，右端伸长 0.01，εx = 0.01 ✓，且不产生 εy 与剪应变。再取 de = [0, 0, 0, 0.01, 0, 0]，得 ε = [0, 0, 0.01]T——纯剪切 ✓。

4.2 应力矩阵 S：从节点位移直达应力

再把 (4.22) 代入物理方程 σ = Dε：

σ = DBde ≡ S de　，　S = DB　(3×6) (4.27)

对平面应力，把 (4.6) 与 (4.23) 相乘，得到子块形式（r = i, j, m）：

Sr = E2A(1 − ν2) brν cr ν brcr 1−ν2cr1−ν2br (4.28)

既然 B 和 D 都是常数矩阵，S 也是常数矩阵，因此单元内应力处处相同。这是 CST 最大的局限，也是它区别于所有高阶单元的标志。

◎ 为什么应力允许跳、位移不允许跳
弹性力学的泛函里只出现位移的一阶导数。为了让 ∫(∂u/∂x)2 dA 有限，u 本身必须连续（否则导数含 δ 函数，平方积分发散），但导数可以有跳跃（分段常数的平方积分完全有限）。 所以有限元只要求 C0 连续，应变和应力的间断是被允许的——这是变分法"弱形式"带来的最大便利。板壳问题的泛函含二阶导数，就必须 C1 连续，单元设计因此困难得多。

正因为存在跳跃，CST 算出的应力不能直接使用，工程上必须做后处理平均（第 10.1 节的绕节点平均法与两单元平均法）。而且还有一条经验：位移的精度远高于应力的精度——位移是直接解出来的主变量，应力是求导后的派生量，求导会放大误差，通常掉一个精度阶。
