8边界条件的施加：让奇异矩阵变得可解

组装完成的 Kd = F 有 2n 个方程、2n 个未知数，看起来可以解了，实际却解不出来：K 的秩只有 2n − 3。物理原因一目了然——结构还没被固定，它可以整体平移和转动，位移不唯一。本章介绍四种消除刚体自由度的方法，并给出它们在精度、效率、编程难度上的取舍。

8.1 三种边界条件

类型数学形式在有限元中怎么处理
位移边界（本质 / Dirichlet）u = u 在 Su 上 必须显式施加。这是本章的主题。
力边界（自然 / Neumann）σ·n = t̄ 在 St 上 不需要施加——它已经被 (4.42) 的面力积分自动满足了。这正是"自然"二字的含义。
自由边界t̄ = 0 什么都不做。零面力是默认状态——这是初学者最容易困惑的一点：不加载荷就是自由边界。
◎ 为什么力边界"自然"而位移边界"本质"
推导最小势能原理时，位移场必须事先满足位移边界条件（属于容许位移场的定义），所以它是泛函本身的本质约束；而力边界条件是变分 δΠ = 0 的副产品（分部积分后的边界项），它自然而然地被满足。 Hughes 第 1–2 章用"essential / natural"这对术语系统地阐述了这个区别，它在所有变分问题中都成立。

8.2 方法一：直接缩减法（划行划列）

最直白的办法：既然某些自由度已知为零，它们就不是未知数，从方程组里删掉。把自由度分成已知（下标 c）与未知（下标 f）两组，方程分块写作

KffKfcKcfKcc dfdc = FfRc (4.66)

若 dc = 0，第一行直接给出

Kff df = Ff　　（阶数降为 2n − nc，且正定） (4.67)

解出 df 后，第二行顺带给出支反力：Rc = Kcfdf。

✓ 优点
阶数真的降低了，存储和计算量都减少；Kff 是严格正定的，条件数不受任何人为干扰；理论上最干净。
✗ 缺点
要建立"整体编号 ↔ 缩减后编号"的映射表，编程繁琐；矩阵要重新搬运一遍，破坏已经建好的带状/稀疏结构；约束一变就得全部重来。

8.3 方法二：化 1 置 0 法（对角元置一）

保持矩阵阶数不变，只把约束自由度对应的那一行、那一列全部清零，对角元改成 1，右端项改成 0（或已知位移值）：

Krs ← 0 (s ≠ r)　， Ksr ← 0 (s ≠ r)　， Krr ← 1　， Fr ← dr (4.68)

这样第 r 个方程退化成 1·dr = dr，强制给出所需的位移值；而把第 r 列也清零，是为了保持矩阵对称（否则无法用 Cholesky 分解）。

▲ 清零第 r 列之前，必须先"移项"
若 dr ≠ 0，第 r 列中的元素 Ksr·dr 对其他方程是有贡献的，不能一删了事，必须先搬到右端：
Fs ← Fs − Ksr · dr　，　对所有 s ≠ r
漏掉这一步是非零强迫位移问题最常见的错误，结果表现为"位移量级对但分布形态不对"。零位移约束时 dr = 0，这一步自动消失，所以很多人从未意识到它的存在。

化 1 置 0 法编程简单、不改变矩阵规模，是教学程序和很多中小型求解器的首选。代价是：被约束的那些方程仍占着存储；而且支反力不能直接从方程读出（那一行已被改写），要另外用 R = Kd − F 用原始的 K 算。

8.4 方法三：乘大数法（罚函数法）

连清零都省了——只在对角元上加一个极大的数：

Krr ← Krr + α　， Fr ← Fr + α · dr　， α = 10p · max(Kii) (4.69)

原理：第 r 个方程变成 ΣKrsds + α dr = Fr + αdr。当 α 远大于其余各项时，方程被 α 项主宰，近似给出 dr ≈ dr。

从能量角度看，这相当于在被约束的自由度上接了一根刚度为 α 的弹簧，在总势能里加了一个罚项 ½α(dr − dr)2。弹簧越硬，约束越准，但矩阵越病态。这是一个典型的取舍：

③ 二者相乘约为常数 ⇒ 不存在"既准又稳"的 α。工程上取 108 ~ 1012，让两边的误差都远小于工程精度即可。
▲ 罚函数法的隐性代价
① 结果是近似的，约束不会被精确满足（表里的 10−11 mm 虽小但不是 0）；
② 破坏了单调下限性质（第 5.7 节四个前提之一），"网格越细位移越大"不再保证；
③ 迭代求解器（共轭梯度等）的收敛速度 ∝ √cond，大 α 会让迭代次数剧增。所以大规模迭代求解一般不用罚函数，改用直接缩减或 Lagrange 乘子。
④ 支反力必须用原始 K 反算，或者直接取 Rr = −α(dr − dr)，即"弹簧被压缩了多少"。

8.5 方法四：Lagrange 乘子法

把约束 Cd = g 用乘子 λ 挂到总势能上：Π* = Π + λT(Cd − g)，对 d 和 λ 分别取驻值，得到扩阶方程组

KCTC0 dλ = Fg (4.70)

约束被精确满足，且 λ 的物理意义正是支反力（相差一个符号），可以直接读出。代价是矩阵扩大、且不再正定（成为对称不定的鞍点问题），需要专门的求解器。它是处理多点约束（MPC）最规范的工具。

8.7 斜支座与多点约束

前面三种方法都假定约束方向与坐标轴平行。若支座是斜的（如滚轴沿与 x 轴成 θ 角的斜面滑动），约束条件是两个自由度的线性组合：

ur sinθ − vr cosθ = 0　（法向位移为零） (4.71)

处理办法有两条：

  1. 局部坐标旋转。对该节点作坐标变换 d′ = T d，其中 T 是 2×2 旋转矩阵。相应地把 K 的第 r 号节点行块与列块都作合同变换 TKrs、KsrTT。新坐标下约束又变成"某个自由度 = 0"，回到方法一～三。这是商业软件的标准做法（ANSYS 的 NROTAT、Abaqus 的 *TRANSFORM）。
  2. 直接作为 MPC 处理。用 (4.70) 的 Lagrange 乘子，或消去从自由度（主从法）。

更一般的多点约束还包括：刚性连接（两节点保持固定距离）、周期性边界（u左 = u右，用于代表性体积单元）、绑定接触（不同密度网格的黏结）。它们统一写成 Cd = g，然后用 Lagrange 乘子或主从消元求解。

8.8 约束是否"足够"：一个必须养成的习惯

▲ 欠约束与过约束
欠约束：残留刚体自由度 ⇒ 求解器报"矩阵奇异""pivot 为零""自由度 N 有刚体运动"。平面问题至少需要三个独立约束（例如一点固定 + 另一点限制一个方向）。
过约束：施加了物理上不存在的约束 ⇒ 结构人为变硬，求解器不会报任何错，只是算出偏小的位移和虚假的支反力。这比欠约束危险得多。
第 9 章的例题五会用同一块板的两种约束方案，定量展示过约束带来的 0.82 % 刚度偏差和本不该出现的 σy。
✓ 求解前后的四条自检清单
① 求解前：数一数约束是否至少消除了 3 个刚体自由度，且没有多余；
② 求解前：检查 K 的对角元是否全部为正、行和是否为零；
③ 求解后：R = Kd − F，验算全部支反力之和 = 外载合力的相反数；
④ 求解后：检查自由节点的"反力"是否为零，被约束节点的位移是否确实等于给定值。
