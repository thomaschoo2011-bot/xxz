6载荷矩阵：分布载荷的积分等效

第 5 章的 (4.34) 已经给出了载荷列阵的表达式，但那只是一个符号。本章把三个积分一个不漏地做出来——这是初学有限元时最容易"背公式而不知所以然"的地方，也是本讲义着墨最多的一章。

6.1 问题：有限元只认识节点力

方程 Kd = F 中，F 的每一行对应一个节点自由度。可是真实结构承受的往往是连续分布的载荷：水压、风压、自重、接触压力……它们作用在单元的边上或整个面积上，而不是"恰好作用在节点上"。

因此必须把分布载荷转化为作用在节点上的集中力。这个转化过程叫载荷移置或等效节点载荷（equivalent nodal load）。问题在于：什么叫"等效"？

6.2 等效的原则：虚功相等

回到 (4.34)。等效节点载荷的定义已经包含在总势能的推导里了，根本不需要额外规定。把外力功项写开：真实的分布载荷做的功是 ∫uTt̄ ds；代入 u = Nde，得 (de)T∫NTt̄ ds。而节点力做的功是 (de)Tfe。令两者对任意 de 相等，立得：

fe = ∫Ae NTb t dA + ∫s NTt̄ t ds + Σk NT(xk) Pk (4.42)

▲ 体力　　▲ 面力 / 线载荷　　▲ 单元内部的集中力

✓ 这个定义为什么是"对"的
① 它不是人为规定，而是最小势能原理的必然产物——用它算出的解，正是使总势能最小的那个解；
② 它自动与位移模式相容：换单元就换 N，公式形式不变；
③ 节点再多也唯一确定，不存在静力等效那种"方程不够"的困境；
④ 它保证收敛。第 5.7 节的单调下限性质要求载荷按能量等效转化，否则不成立。

6.3 体力的等效：自重的 W/3 是怎么来的

取 (4.42) 第一项，体力 b = [bx, by]T 在单元内为常数（自重就是如此）。把 NT（6×2）展开，第 1 行是 [Ni, 0]，第 2 行是 [0, Ni]，依此类推，于是

fe体力 = t bx ∬ Ni dA by ∬ Ni dA bx ∬ Nj dA by ∬ Nj dA bx ∬ Nm dA by ∬ Nm dA (4.43)

三个积分完全一样，用第 3.4 节的面积坐标公式 (4.19)，取 (a,b,c) = (1,0,0)：

∬A Ni dA = ∬A L1 dA = 1! · 0! · 0!(1+0+0+2)! · 2A = 16 · 2A = A3 (4.44)

代回，对自重 b = [0, −ρg]T，记单元总重 W = ρg · tA：

fe自重 = −W3 [ 0　1　0　1　0　1 ]T (4.45)
◎ 巧合还是必然？
三节点三角形的自重按 1 : 1 : 1 三等分——这恰好与静力等效（把重量放在形心，再按杠杆分配给三个顶点）的结果一致，因为三角形的形心正是三顶点的算术平均。 但这只是 CST 的巧合。换成 6 节点 LST，自重的能量等效结果是角节点各得 0、中节点各得 W/3——角点分到的竟然是零！这在静力等效的框架下完全无法想象。 这就引出了 6.6 节的主题。

6.4 线载荷与面力的等效：核心推导

这是本章的主干。设分布载荷作用在单元的一条边 ij 上，边长 L，板厚 t。沿边建立弧长坐标 s，s = 0 在节点 i，s = L 在节点 j。

6.4.1 第一步：把形函数限制到边上

由形函数性质 ③（第 3.3 节），在边 ij 上有 Nm ≡ 0，而 Ni、Nj 沿边线性变化，且在两端取 1 和 0。所以不必代入 (4.14) 那套 a、b、c，直接写出边上的一维形函数：

Ni(s) = 1 − sL = 1 − ξ　， Nj(s) = sL = ξ　， Nm(s) ≡ 0 (4.46)
✓ 一个立刻能用的结论
Nm ≡ 0 意味着：作用在边 ij 上的任何载荷，都不会分配给对面的节点 m，一丝一毫都不会。 这大大简化了手算——只需考虑受载边的两个节点。

6.4.2 第二步：一条主公式

观察 (4.42) 第二项的结构：被积函数总是"形函数 × 载荷函数"。如果载荷是多项式（工程中绝大多数情况），那么被积函数一定是 (1−ξ)aξb 这类项的线性组合。于是只要把这一种积分一次算清楚，所有多项式分布载荷就全解决了。

∫0L Nia Njb ds = ∫0L (1−ξ)aξb ds = a! · b!(a + b + 1)! · L (4.47)
主公式 (4.47) 的推导（三行）

换元 ξ = s/L，ds = L dξ，积分限变成 0 → 1：

∫0L(1−ξ)aξb ds = L ∫01(1−ξ)aξb dξ = L · B(b+1, a+1)

右边是 Beta 函数，它与 Gamma 函数（整数时即阶乘）的关系是

B(p, q) = Γ(p)Γ(q)Γ(p+q) = (p−1)! (q−1)!(p+q−1)!

代 p = b+1、q = a+1，即得 (4.47)。注意公式对非整数指数同样成立（用 Gamma 函数），所以连 ξ1/2 这类分布也能直接套。

6.4.3 情形一：均布线载荷

设沿边作用方向不变、大小恒为 q（单位：力/长度，若给的是面压强 p，则 q = p·t）。以 y 向为例：

Fyi = ∫0L Ni · q · t ds = qt ∫0L(1−ξ) ds = qt · 1!·0!2!L = qtL2 (4.48)

同理 Fyj = qtL/2。合力 qtL 与真实合力一致，各分一半。这条结论与直觉完全吻合，也是大多数人唯一记得住的一条——但下面就开始不一样了。

6.4.4 情形二：均布面载荷（体力式）

若"均布面载荷"指的是作用在整个单元面积上的压力（如楼板上的活荷载 p，单位 N/m2，但沿厚度方向压在面上），就要按体力处理：把它折算成体力 by = −p/t，代入 (4.45)：

Fyi = Fyj = Fym = −pA3 (4.49)
▲ 区分三种"分布载荷"，别混淆量纲
名称符号量纲作用位置用哪一项
体力bN/m3单元体积内(4.42) 第 1 项，面积分
面力 / 压强t̄N/m2单元的边（侧表面）(4.42) 第 2 项，线积分 ×t
线载荷qN/m单元的边(4.42) 第 2 项，线积分（q = t̄·t）
考试和实际建模中错得最多的就是这里：把 N/m2 的压强当成 N/m 的线载荷用，结果差一个厚度 t。做完一定要用"总合力"反查一遍。

6.4.5 情形三：线性（三角形）分布——非均布的起点

设 q(s) = q0(1 − s/L) = q0(1 − ξ)，即在节点 i 处最大为 q0，在节点 j 处降为零。代入积分：

Fi = ∫0L (1−ξ) · q0(1−ξ) · t ds = q0t ∫0L(1−ξ)2 ds = q0t · 2!·0!3!L = q0tL3 (4.50)
Fj = ∫0L ξ · q0(1−ξ) · t ds = q0t · 1!·1!3!L = q0tL6 (4.51)

校核：合力 = q0tL/3 + q0tL/6 = q0tL/2，正是三角形载荷图的面积 ✓。分配比 2 : 1，靠近载荷大的一端分得多——符合直觉，而且数值上与材料力学按形心杠杆分配的结果恰好相同（形心距 i 为 L/3，杠杆分配给 i 的比例为 1 − 1/3 = 2/3 ✓）。

6.4.6 情形四：抛物线分布

设 q(s) = 4q0ξ(1 − ξ)，两端为零、中点最大为 q0（系数 4 是为了让中点 ξ = 1/2 处取 q0）。这是压力容器接管、薄膜受压等场合的典型分布。

Fi = 4q0t∫0L(1−ξ)2ξ ds = 4q0t · 2!·1!4!L = 4q0t · L12 = q0tL3 (4.52)

由对称性 Fj = q0tL/3，合力 2q0tL/3，正是抛物线下的面积（2/3 × 底 × 高）✓。分配比 1 : 1。

6.4.7 情形五：二次幂分布

设 q(s) = q0ξ2，在 i 端为零、在 j 端达到 q0，中间凹。

Fi = q0t∫(1−ξ)ξ2 ds = q0t1!·2!4!L = q0tL12 　， Fj = q0t∫ξ3 ds = q0t0!·3!4!L = q0tL4 (4.53)

合力 q0tL(1/12 + 1/4) = q0tL/3 ✓（∫ξ2dξ = 1/3）。分配比 1 : 3——高度不对称。

6.4.8 工程实例：挡土墙上的静水压力

例题 4-2　水深 4 m 的直立墙面，求单元边的等效节点载荷

题设：竖直墙面，水从顶面（y = 0）到底部（y = 4 m）。水的重度 ρg = 9800 N/m3。按平面应变取单位厚度 t = 1 m。整个 4 m 高度用一个单元边（L = 4 m）承担，节点 i 在水面、j 在底部。

第 1 步　写出载荷函数。静水压强随深度线性增长：p(y) = ρg y。在底部达到最大值

q0 = ρg · h = 9800 × 4 = 39 200 N/m2

用弧长坐标（s 从水面向下）：q(s) = q0 ξ，ξ = s/L。这是 6.4.5 的反向线性分布。

第 2 步　积分。

Fi = q0t∫0L(1−ξ)ξ ds = q0t · 1!1!3!L = q0tL6
Fj = q0t∫0Lξ2 ds = q0t · 0!2!3!L = q0tL3

第 3 步　代数。q0tL = 39 200 × 1 × 4 = 156 800 N

量公式数值占比
Fi（水面节点）q0tL/626.13 kN1/3
Fj（底部节点）q0tL/352.27 kN2/3
合计q0tL/278.40 kN100 %

第 4 步　独立校核。水压力的合力应当等于压力三角形的面积乘厚度：

P = 12ρg h2 t = 12 × 9800 × 42 × 1 = 78 400 N = 78.40 kN ✓

合力矩也可核对：等效节点力对水面的力矩 = 52.27 × 4 = 209.1 kN·m；真实压力的合力作用在 2h/3 = 2.667 m 处，力矩 = 78.40 × 2.667 = 209.1 kN·m ✓。两个校核全部通过。

◎ 实用提醒
用一个单元边跨越整个 4 m 水深，等效载荷是精确的（因为载荷是线性的，被积函数二次，主公式精确积分），但位移解不会精确——CST 的位移模式只有一次，无法表示真实的三次挠度曲线。 工程中沿水深至少划分 8～16 个单元。等效载荷"精确"与整体解"精确"是两回事。

6.7 能量等效 ≠ 静力等效：一个必须知道的反例

对 CST 而言，能量等效与静力等效给出的结果恰好一致（均布 1:1、线性 2:1、自重 1:1:1），于是很多人误以为"等效节点载荷 = 按杠杆分配"。这个误解在遇到高阶单元时会立刻出错。

考察 8 节点四边形（Q8）的一条边，上面有三个节点：两个角节点 1、3 和一个中节点 2。边上的形函数是二次的（自然坐标 ξ ∈ [−1, 1]）：

N1 = ½ξ(ξ − 1)　， N2 = 1 − ξ2　， N3 = ½ξ(ξ + 1) (4.54)

边上均布载荷 q0，雅可比 ds = (L/2)dξ：

F1 = q0tL2∫−11½(ξ2 − ξ) dξ = q0tL2 · 13 = q0tL6 (4.55)
F2 = q0tL2∫−11(1 − ξ2) dξ = q0tL2 · 43 = 2q0tL3 (4.56)
▲ 结果：1/6 : 2/3 : 1/6，而不是 1/4 : 1/2 : 1/4
中节点分到了三分之二，比两个角节点加起来还多一倍。合力 q0tL(1/6 + 2/3 + 1/6) = q0tL 仍然正确 ✓，但分配方式与任何"按面积分摊"的直觉都对不上。
如果按静力直觉手工输入 1/4 : 1/2 : 1/4，算出的位移解不是该网格下的最优解，而且会破坏第 5.7 节的收敛性质。

更极端的例子：Q8 一条边上作用线性分布载荷（节点 1 处为 0、节点 3 处为 q0），积分给出

F1 = 0　， F2 = q0tL3　， F3 = q0tL6 (4.57)

零载荷那一端的角节点分到的是精确的零，而中节点分到的是另一个角节点的两倍。合力 q0tL/2 依然正确 ✓。Felippa 在 IFEM 第 23 章把这类结果称为 "consistent nodal forces"——一致节点力，强调它们与单元的插值函数"一致"，而非与静力直觉一致。

6.8 单元内部的集中力

若一个集中力 P 不幸作用在单元内部的点 (xP, yP)（网格划分时应尽量避免，但有时无法避免），(4.42) 第三项给出

Fxi = Ni(xP, yP) · Px　， Fxj = Nj(xP) · Px　， Fxm = Nm(xP) · Px (4.58)

即按该点的形函数值（面积坐标）分配。由单位分解性质，三份之和恰为 Px，合力自动守恒 ✓。若 P 恰在形心，则三节点各得 P/3。

6.9 从单元载荷到整体载荷列阵

各单元算出 fe 后，与单刚一样"对号入座"累加到整体 F 的对应行：

F = Σe Ge fe + P节点 (4.59)

其中 P节点 是直接作用在节点上的集中力，无需任何转化，直接填入即可。

✓ 载荷组装的一条重要校核
组装完毕后，把 F 中所有 x 方向分量相加，应等于全部外载荷的 x 合力；y 方向同理。 这条校核只需几行代码，却能抓住绝大多数载荷输入错误（漏边、重复加载、方向反了、忘乘厚度）。第 9 章的例题三会用它来验证支反力。
▲ 相邻单元共享受载边时不要重复计算
内部边上的面力在两个单元中大小相等、方向相反，组装后自动抵消——这正是内力不出现在整体方程中的原因。 但如果你在建模时手工给两个单元都加上了同一条外边界上的压力，载荷就会翻倍。 商业软件按"面（face）"施加载荷正是为了避免这个陷阱。
