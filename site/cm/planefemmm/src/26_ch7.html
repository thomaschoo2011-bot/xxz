7单刚组装总刚：对号入座

到这里，每个单元都有了自己的 6×6 刚度矩阵 ke 和 6×1 载荷列阵 fe。但它们各说各话——单元 ① 的"第 3 个自由度"和单元 ② 的"第 3 个自由度"很可能指的是结构上完全不同的两个方向。本章把这些局部的小矩阵缝合成描述整个结构的大方程。

7.1 组装的两个等价依据

依据一：节点平衡
把任一节点单独取出来作隔离体，围绕它的所有单元都对它施加内力。节点的平衡方程是
Σe Fe节点 = P节点
而每个单元施加的内力就是 kede 中对应的行。于是总刚的某一行 = 环绕该节点的各单元对应行之和。
依据二：能量叠加
结构的总应变能是各单元应变能之和：U = Σe Ue。把 (4.32) 全部用整体位移列阵 d 表示后相加，括号里自然出现
K = Σe (扩大后的 ke)
这条路线更形式化，也更容易写成程序。

两条路线殊途同归，得到的都是同一句话：整体刚度矩阵的每个元素，等于所有相关单元刚度矩阵对应元素的代数和。这就是刚度集成法（direct stiffness method）。

7.2 形式化写法：贡献矩阵

引入 6×2n 的布尔定位矩阵 Ge（每行只有一个 1，其余全 0），它把整体位移列阵"抽取"成单元位移列阵：

de = Ge d　，　(6×1) = (6×2n)(2n×1) (4.60)

代入 (4.32) 并对所有单元求和：

K = Σe=1ne (Ge)T ke Ge 　， F = Σe=1ne (Ge)T fe (4.61)

(Ge)TkeGe 是一个 2n×2n 的大矩阵，但只有 6×6 = 36 个位置非零——它叫这个单元的贡献矩阵（或扩大矩阵）。总刚就是把所有贡献矩阵"摞"在一起相加。

▲ 公式好看，但千万别这么编程
(4.61) 是理论表述。若真的构造 Ge 并做两次矩阵乘法，每个单元要做 O((2n)2·6) 次乘法，其中 99.99 % 是在和 0 相乘。 10 万自由度的模型这样组装要跑上几天。实际程序一律用下一节的定位数组，把它变成 36 次加法。

7.3 实用做法：LM 定位数组与"对号入座"

节点编号 n 的两个自由度在整体列阵中的行号是

x 方向：2n − 1　，　y 方向：2n (4.62)

对每个单元，按局部节点顺序 (i, j, m) 列出 6 个整体行号，存成一个长度为 6 的数组，这就是定位数组 LM（location matrix）。组装的全部代码只有四行：

for e in elements:                  # 遍历单元
    LM = [2*i-1, 2*i, 2*j-1, 2*j, 2*m-1, 2*m]
    for a in range(6):
        for b in range(6):
            K[LM[a]][LM[b]] += k_e[a][b]     # 对号入座，累加
✓ 记住"累加"这两个字
是 += 而不是 =。多个单元共享同一个节点时，它们对同一个位置的贡献必须叠加。 写成赋值是初学者最常见的 bug——程序不会报错，但算出的结构会比实际软得多（后来的单元把前面的覆盖掉了）。

7.5 例题二：五节点四单元的完整组装

例题 4-3　边长为 1 的正方形板，中心加一个节点划成 4 个三角形，求总刚的结构（平面应力，ν = 1/3，厚 t）

题设：节点 1(0,0)、2(1,0)、3(1,1)、4(0,1)、5(0.5, 0.5)。四个单元均逆时针：

第 1 步　算一个单刚的关键子块。以单元 ① 为例，节点顺序 (1, 2, 5)。对节点 5（局部第三个），由 (4.15) 轮换：

b5(1) = y1 − y2 = 0 − 0 = 0　， c5(1) = x2 − x1 = 1 − 0 = 1　， A(1) = 0.25

代入 (4.39)，ν = 1/3 时 (1−ν)/2 = 1/3、1−ν2 = 8/9、4A = 1，故前系数 = 9Et/8：

k(1)55 = 9Et8 0 + ⅓·1001 + 0 = Et0.375001.125 (4.63)

第 2 步　利用对称性推其余三个。单元 ② 相当于把单元 ① 绕中心转 90°，于是 b5(2) = −1、c5(2) = 0，两个对角元互换：

k(2)55 = Et1.125000.375

单元 ③、④ 与 ①、② 分别相同（转 180°，b、c 变号，而 (4.39) 中 b、c 成对出现，同时变号结果不变）。

第 3 步　累加得 K55。四个单元都含节点 5，全部叠加：

K55 = 2Et0.375001.125 + 2Et1.125000.375 = 3Et 1001 (4.64)
✓ 一个漂亮的结果
中心节点的刚度子块是各向同性的——沿任何方向推它，得到的抵抗力大小相同、方向与推力共线。 这是网格四重对称性的必然结果：四个单元轮换 90° 后完全重合，叠加出的张量必须在 90° 旋转下不变，二阶对称张量满足此条件的只有 λI。 这个推理不需要算任何数就能得到，可以反过来用作程序的校核。

7.6 总刚的性质：单刚性质的"放大版"

性质表述与单刚的关系 / 用途
① 对称KT = K 由 (4.61)，对称矩阵的合同变换仍对称。存储与求解均可减半。
② 稀疏Krs ≠ 0 仅当 r、s 同属某单元 单刚是满的，总刚却极稀疏——自由度越多越稀疏。大规模计算的全部希望都在这条性质上。
③ 带状非零元集中在主对角线附近 由 ② + 合理编号得到。半带宽由 (4.9) 估算。
④ 奇异秩 = 2n − 3 与单刚的秩亏 3 同源：整个结构仍可自由飘移。施加边界条件前不能求解。
⑤ 主对角元恒正Krr > 0 由单刚性质 ④ 累加而来。程序中若出现非正对角元，必定是建模或组装有错——最常用的自检。
⑥ 行和为零各 x-列之和 = 0 刚体平动不生内力，对整体依然成立。组装完立即验一次，能抓住绝大多数 LM 索引错误。
⑦ 约束后正定施加足够约束 ⇒ K 正定 正定才能用 Cholesky（LLT）分解，且分解过程无需选主元，数值稳定。

7.7 存储格式：从带状到稀疏

10 万自由度的模型，满阵存储需要 1010 个双精度数 = 80 GB，显然不可行。工程软件用的是下面三种之一：

等带宽存储
2n × B
把每行带内的元素平移到左端，存成矩形数组。实现最简单，但若个别行带宽特别大就会浪费。
变带宽 / 天际线
Skyline
每列只存从第一个非零元到对角元。Bathe 的 Finite Element Procedures 第 8 章详细讨论了它与 LDLT 分解的配合。
通用稀疏 CSR
values / col / rowptr
只存非零元及其位置，配合 AMD/METIS 重排序与多波前分解。现代求解器的标准做法，编号顺序不再关键。
◎ 组装本身也能并行
由于组装只是"累加"，不同单元的贡献互不依赖，天然可并行。唯一的麻烦是两个线程可能同时写同一个位置（竞态）。 常用解法有三种：按颜色给单元分组（同色单元互不共享节点）、每线程各自组装再归约、或用原子加。 GPU 有限元程序几乎都采用第一种"图着色"策略。
▲ 组装完成 ≠ 可以求解
此刻的 K 仍然奇异，det K = 0，直接调用求解器会得到"矩阵奇异"或一堆 NaN。 必须先施加位移边界条件，消掉那 3 个刚体自由度——这正是下一章的任务。
