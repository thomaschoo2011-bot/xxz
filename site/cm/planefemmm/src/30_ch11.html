11.1 一页纸的逻辑链

整个方法只有一条主线：用分片多项式代替未知的真实位移场，让总势能最小。所有看起来五花八门的技巧——形函数、面积坐标、等效节点力、对号入座、化 1 置 0、绕节点平均——都是这条主线在不同环节上的具体实现。把它们串起来就是：

如果只允许写一行公式来概括这一整章内容，那就是把第 5、6、7 章合成一句话——单元的能量求和等于整体的能量，于是单元矩阵的"对号入座求和"就等于整体矩阵：

Π = ½dTKd − dTF　， K = Σe (Ge)T ∫Ae BTDB t dA · Ge　， F = Σe (Ge)T (∫Ae NTb t dA + ∫Ste NTt̄ t ds)
⇒　δΠ = 0　⇒　Kd = F　（加上位移边界条件后唯一可解） (4.89)
离散→假设 u = Nd→求导 ε = Bd→代入 Π→δΠ = 0→kᵉ、fᵉ→对号入座→加约束→解 d→回代求 σ→平均与收敛校核
◎ 为什么"位移法"能一统天下
(4.89) 的形式对任何单元、任何维数、任何材料都不变：换单元只换 N，换材料只换 D，换维数只换积分区域。 正因为这种彻底的模块化，同一套求解器可以同时处理杆、梁、板、三维实体；也正因为如此，第 3 章的杆件讲义和本章的平面问题讲义在结构上是逐条对应的——你只要把 B = [−1/L　1/L] 换成 (4.23) 的 3×6 矩阵，把 EA 换成 Dt，整条推导一字不改。

11.3 必须记住的十四个结论与数字

✓ 概念类（记不住就会出错）
① 平面应力是薄板受面内力，平面应变是长柱受横向力；判错会让 σz 和横向刚度全错。
② 三节点三角形单元内应力是常数，所以它永远画不出弯曲的线性应力分布——弯曲问题用 CST 必须靠网格密度硬堆。
③ 收敛准则 = 完备性 + 协调性。完备性由 Pascal 三角形的完全多项式保证，协调性由共享边上位移相同保证。
④ 有限元位移解偏小（结构偏硬），这是最小势能原理的下限性质；四个前提（位移法、精确积分、协调元、精确施加约束）缺一不可。
⑤ 力边界条件不需要施加（自然），位移边界条件必须施加（本质）。不加载荷 = 自由表面。
⑥ 欠约束会报错，过约束不会报错——后者危险得多，要靠"约束是否有物理依据"来人工排查。
⑦ 单元应力精度比位移低一档；以应力为判据的设计必须比"位移收敛"再密一档网格。
⑧ 真正的应力奇异点永远不收敛，加密只会得到更大的值；此时要换判据或改模型。
✓ 数字类（考试和手算都要用）
⑨ 半带宽系数 f = 2（平面问题每节点 2 个自由度）；K 的秩亏为 3（两平动一转动）。
⑩ 自重等效到三角形三个节点：各 W/3；这是面积坐标积分 ∬Ni dA = A/3 的结果。
⑪ 均布线载荷等效到两端节点：各 qtL/2（对半分）；三角形分布（0→q）：1:2（qtL/6 与 qtL/3）；抛物线分布（两端 0、中间 q）：1:1，各 qtL/3；二次幂分布（q(s/L)2）：1:3（qtL/12 与 qtL/4）。
⑫ Q8 单元边上均布载荷按 1/6 : 2/3 : 1/6 分配——角节点比中节点少得多，与直觉相反，是最容易记错的一条。
⑬ 罚因子 α = 108~1012 × max Kii；单元长宽比 < 3，最小内角 > 30°。
⑭ 位移收敛阶 O(h2)（误差每加密一次降为 1/4）；跳跃量收敛阶 O(h)；绕节点平均后的应力恢复到 O(h2)。
▲ 三条最容易失分的细节
① CST 的节点必须逆时针编号，否则 2A < 0，B 反号、ke 不变但应力符号全错（因为 ke 中 B 出现两次而 σ 中只出现一次）；
② 非零强迫位移时必须移项（8.3 节）；
③ 对称模型算出的支反力和总载荷要按对称倍数还原（例题 4-7：2 000 kN → 4 000 kN），而位移和应力不还原。

11.4 思考题

下面八题都不需要计算器，但每一题都对应一个真实的工程陷阱。先自己想，再展开看答案。

思考题 1（单元阶次 vs 网格密度）　同样的自由度预算，是用少量 Q8 还是大量 CST？

答：绝大多数情况下用高阶单元。第 10.5 节的实测表给出了直接证据：要达到 1.5 % 的挠度精度，CST 需要 1 122 个自由度，Q4 只要约 300 个，而 Q8 会更少。原因是误差 ∝ hp+1，提高阶次 p 的收益是指数级的，而加密 h 的收益是多项式级的。

但有三个例外：① 几何非常复杂、需要靠小单元贴合边界时；② 存在应力奇异点，此时高阶单元的优势消失（真解不光滑，p 收敛失效）；③ 接触、大变形等强非线性问题，高阶单元的中节点容易引起数值困难，工业界反而偏好线性单元 + 密网格。
思考题 2（为什么 ke 的行和必须为零）

答：令单元做刚体平移 de = [1,0,1,0,1,0]T（所有节点沿 x 移动一个单位）。刚体运动不产生应变，因此不产生内力，必须有 kede = 0，展开正是"每行中所有 x 方向列之和为零"。同理取 y 方向平移得另一组。这也解释了 ke 的秩为 6 − 3 = 3。

工程用途：这是检查自编程序最快的一招——把 ke 的奇数列相加、偶数列相加，两个结果都应是机器零。若不为零，B 矩阵里的 bi、ci 轮换必然写错了。
思考题 3（集中力能不能直接加在节点上？）

答：可以，而且不需要任何等效计算——(4.42) 的第三项在集中力恰好作用于节点时退化为力本身（因为 Ni 在节点 i 处为 1、其余为 0）。

但要清楚代价：集中力在弹性理论中对应应力奇异点（二维问题里 σ ~ ln r 或 1/r 量级）。加载点附近的应力永远不收敛，加密网格只会算出越来越大的值。若关心的正是加载点附近的应力，就必须把集中力改成真实的分布压力（接触面积上的 p = P/A），这也是 Saint-Venant 原理在有限元里的实际含义：距加载点一个特征长度以外的结果不受这个建模细节影响。
思考题 4（对称性用错了会怎样）

答：三个典型错误。① 反对称载荷用了对称边界：例如纯弯的梁取一半却令对称面 u = 0，这会人为堵死本该发生的转动，结果偏硬且完全错；反对称问题应令对称面上切向位移为零（平面 ⊥ x 时是 v = 0）。② 忘了还原倍数：取 1/4 模型算出的总反力是真实值的 1/4，载荷也只能加 1/4（例题 4-7）。③ 用对称性掩盖了失稳或非对称失效：屈曲、裂纹、接触滑移的真实模式常常是非对称的，对称模型结构上排除了这些解，会给出危险的乐观结果。

结论：对称性是只在线性、对称载荷、对称约束、对称材料同时成立时才能用的加速手段，不是无条件的建模技巧。
思考题 5（为什么不直接用更精确的积分或更多高斯点？）

答：因为"更精确的积分"并不等于"更精确的解"。ke 的被积函数 BTDB 对 CST 是常数、对规则 Q4 是低次多项式，2×2 高斯积分已是精确的，再加点毫无收益。

更有意思的是反方向：Q4 存在剪切自锁，有意采用减缩积分（1 个高斯点）反而能消除虚假剪切刚度，让细长单元的弯曲表现大幅改善——代价是引入沙漏模式（零能模式），需要额外的沙漏控制。商业软件中的 "reduced integration + hourglass control"（Abaqus 的 CPS4R）正是这条思路。可见积分方案是单元设计的一部分，而不是单纯的数值精度问题。
思考题 6（ν → 0.5 时发生了什么）

答：平面应变下 D 中含 1/(1−2ν) 因子，ν → 0.5 时体积模量 K = E/[3(1−2ν)] → ∞，材料趋于不可压缩。低阶位移单元无法在逐点满足 εx + εy = 0 的同时还保留足够的变形自由度，于是被"锁死"——位移严重偏小、应力出现剧烈振荡，这就是体积自锁（volumetric locking）。

三条出路：① 混合格式（把压力 p 作为独立未知量，u/p 单元）；② 减缩积分或选择性减缩积分（只对体积项降阶）；③ B-bar / F-bar 方法（把体积应变在单元上取平均）。橡胶、饱和土、塑性流动（塑性不可压）都会遇到这个问题，所以它在工程中远比听起来常见。平面应力不受影响，因为板厚方向可以自由收缩。
思考题 7（跳跃量小一定说明网格好吗）

答：不一定。第 10.6 节的表给出了反例：2×1 网格的跳跃量 3.05 MPa 反而小于 4×2 的 6.76 MPa，但 2×1 的结果错得多。原因是当网格太粗时，应力场整体被算小了，差值自然也小——跳跃量小是"都算小了"而不是"都算准了"。

所以误差指示器只有在网格进入渐近收敛区之后才可信。判断是否进入渐近区的唯一办法是至少算三套网格，看关键量是否单调、比值是否趋于 2p。这正是把"网格收敛研究"写进规范（ASME V&V）而不是只要求"跳跃量小于 5 %"的原因。
思考题 8（商业软件给你看的应力，是哪一个？）

答：默认几乎总是绕节点平均后的值（甚至是 SPR 恢复后的值），并且在单元内用形函数插值成连续云图。这意味着：

① 你看到的峰值应力比任何单元的原始应力都低——平均本质上是一次低通滤波；
② 跨材料界面、跨厚度突变处的云图可能是错的，除非软件按材料/属性分组平均（多数软件有这个选项，但需要手动开启）；
③ 做强度校核、写报告时，必须写清楚给出的是单元应力（unaveraged / element nodal）还是平均应力（averaged / nodal）。规范审查时这一条经常被追问。

实用建议：同时看两张图。平均图用来判断应力分布形态是否合理，未平均图用来判断网格是否够密（阶梯有多明显）。两张图差别很大的地方，就是必须加密的地方。

    (a) 厚 8 mm 的钢板，四周受面内拉力；
    (b) 长 200 m 的重力坝坝体横截面；
    (c) 内压作用下的长直厚壁管道（远离两端）；
    (d) 受横向弯曲的薄板。
    答案要点：(a) 平面应力；(b)(c) 平面应变；(d) 两者都不是——板弯曲的位移垂直于板面，属于板壳理论，不是平面问题，这是本题的陷阱。
    平面应力 D = E1−ν2[[1,ν,0],[ν,1,0],[0,0,(1−ν)/2]] = 31.25 GPa × [[1,0.2,0],[0.2,1,0],[0,0,0.4]]；
    平面应变按 (4.8) 替换：E′ = E/(1−ν2) = 31.25 GPa，ν′ = ν/(1−ν) = 0.25，代回同一式得 33.333 GPa × [[1,0.25,0],[0.25,1,0],[0,0,0.375]]。注意平面应变的刚度更大。

    (a) 判断编号是否逆时针，算出 2A 与 A；
    (b) 写出全部 ai、bi、ci 与三个形函数；
    (c) 验证在形心处三个形函数都等于 1/3，且 ΣN ≡ 1 对任意点成立；
    (d) 写出 3×6 的 B 矩阵；
    (e) 用 (4.20) 算出 ∬Ni2 dA 与 ∬NiNj dA。
    答案要点：(a) 2A = +2（正，逆时针 ✓），A = 1 m2；
    (b) b = [yj−ym, ym−yi, yi−yj] = [−1, 1, 0]，c = [xm−xj, xi−xm, xj−xi] = [−2, 0, 2]，a = [2, 0, 0]；
    Ni = 1 − x/2 − y，Nj = x/2，Nm = y；
    (c) 形心 (2/3, 1/3)：1−1/3−1/3 = 1/3 ✓，1/3 ✓，1/3 ✓；三式相加恒为 1 ✓；
    (d) 2A·B = [[−1,0,1,0,0,0],[0,−2,0,0,0,2],[−2,−1,0,1,2,0]]，即 B = 该矩阵 /2；
    (e) ∬Ni2 dA = (2!0!0!/4!)·2A = A/6 = 0.1667 m2；∬NiNj dA = (1!1!0!/4!)·2A = A/12 = 0.0833 m2。

  3. 习题 3（非均布载荷的积分等效）★　单元一条边长 L、厚 t，边上两端节点记作 i、j。用母公式 (4.47) 推导下列分布压力的等效节点力，并逐一验算合力与合力矩：
    (a) 线性分布，i 端为 q1、j 端为 q2（一般梯形）；
    (b) 三次分布 q(s) = q(s/L)3；
    (c) 正弦分布 q(s) = q sin(πs/L)（此题需真做积分，母公式不适用）。
    答案要点：(a) fi = tL(2q1+q2)/6，fj = tL(q1+2q2)/6；令 q1=q2=q 退化为 qtL/2 ✓，令 q1=0 退化为 1:2 ✓。合力 tL(q1+q2)/2 = 梯形面积 ✓。
    (b) Ni = 1−ξ、Nj = ξ，q = qξ3：fi = qtL∫(1−ξ)ξ3dξ = qtL(1/4−1/5) = qtL/20，fj = qtL/5 = 4qtL/20，比例 1:4；合力 qtL/4 = ∫ξ3 ✓。
    规律：q ∝ ξn 时比例恒为 1 : (n+1)（n=0 → 1:1、n=1 → 1:2、n=2 → 1:3、n=3 → 1:4），这是 (4.47) 的一个漂亮推论。
    (c) fi = fj = qtL/π ≈ 0.3183qtL（由对称性必相等）；合力 2qtL/π ≈ 0.6366qtL = ∫sin ✓。与抛物线分布的 1:1、各 qtL/3 ≈ 0.3333qtL 相当接近——这解释了工程上常用抛物线近似正弦载荷。

    (a) 检查两个单元的编号是否逆时针；
    (b) 写出对称面与固支端应施加的全部约束，数一数剩下几个未知量；
    (c) 把上边 3–4 的均布压力等效为节点力；
    (d) 求解位移，用 qa/E 表示；
    (e) 求两个单元的应力与全部支反力，校核自平衡；
    (f) 与 Euler 梁和 Timoshenko 梁的理论挠度比较，评价这个两单元模型。
    答案要点：(a) 两个单元的 2A 都等于 +a2 > 0 ✓（这是本题设计的关键——"交叉"式的局部编号 2-3-1 和 3-2-4 都是逆时针）。
    (b) 对称面 x = 0 上的节点 1、3 令 u = 0（法向位移为零，切向自由）；固支端 x = a 上的节点 2、4 令 u = v = 0。8 个自由度中约束了 6 个，只剩 v1 和 v3 两个未知量——所以这道题真的可以手算到底。
    (c) 边 3–4 长 a，均布 ⇒ 节点 3、4 各 −qta/2（向下），总计 −qta。
    (d) v1 = −(8/7)qa/E ≈ −1.1429 qa/E，v3 = −(32/21)qa/E ≈ −1.5238 qa/E（与 t 无关，因为载荷与刚度都 ∝ t）。取 a=1 m、t=10 mm、E=210 GPa、q=1 MPa 时 qa/E = 0.0047619 mm，得 v1 = −0.005442 mm、v3 = −0.007256 mm。
    (e) 单元 ① σ = q(−1/7, −3/7, +3/7) ≈ q(−0.143, −0.429, +0.429)；单元 ② σ = q(0, 0, +4/7)。支反力（以 qta 为单位）：节点 1 (−1/7, 0)、节点 2 (−5/14, +3/14)、节点 3 (+3/14, 0)、节点 4 (+2/7, +11/14)。ΣRx = 0 ✓；ΣRy = 3/14 + 11/14 = 1 × qta，恰等于半模型上的外载 ✓（全梁的实际支反力为 2qta，需按对称倍数还原）。
    (f) 参照解：全梁两端固支 + 满跨均布，w = qt，跨中 Euler 挠度 wL4/(384EI) = 0.5 qa/E；剪切附加项 1.2wL2/(8GA) = 1.6 qa/E，Timoshenko 合计 2.1 qa/E。有限元给出的对称面平均挠度 (1.1429+1.5238)/2 = 1.3333 qa/E，仅为 Timoshenko 解的 63.5 %——偏小，符合下限性质 ✓。
    三条必须写进结论的评价：① L/h = 2 的深梁，剪切变形占总挠度的 76 %（1.6/2.1），绝对不能用 Euler 梁；② 固支端真实的弯曲应力为 M端 = qta2/3，表面 σx = ±2q，而两单元模型最大只给出 0.143q——差一个数量级以上，因为 CST 的常应力根本无法表示线性弯曲应力；③ 结论：这个模型只能用来演示流程，工程上至少需要第 10 章那样 16×8 量级的网格，或者直接改用 Q8。
  5. 习题 5（约束诊断）　对第 9 章例题五那块 2 m × 1 m 的板（节点 1(0,0)、2(0,1)、3(2,0)、4(2,1)），判断下列四种约束方案属于欠约束、恰当约束还是过约束，并预测它对位移和应力的影响方向：
    (a) 仅固定节点 1 的 u、v；
    (b) 固定节点 1 的 u、v 和节点 2 的 u；
    (c) 固定节点 1、2 的 u、v（左边整边固支）；
    (d) 固定节点 1、2 的 u、v，再额外固定节点 3 的 v。
    答案要点：(a) 欠约束：消去了 2 个平动但转动仍自由，Kff 奇异，求解器报错。
    (b) 恰当约束：3 个约束正好消去 3 个刚体自由度，且都有物理依据（这就是例题 4-5 的 Case A）。单轴拉伸时给出 精确解 σx = 2 MPa、σy = 0，因为它允许左边界自由收缩。
    (c) 过约束（相对于"单轴拉伸"这个物理问题）：多约束了 v2，堵死了泊松收缩。结果：结构偏硬（例题 4-5 实测 u3 偏小 0.82 %、应变能偏小 5.57 %），并出现本不该有的 σy 和 ±6.68 kN 的虚假竖向反力。求解器不会给任何警告。注意：若真实构件确实焊死在刚性基础上，(c) 才是对的——过约束与否取决于物理，不取决于数学。
    (d) 严重过约束：节点 3 在自由端，固定它的 v 等于凭空加了一个支座，会把悬臂变成简支，位移和应力定性地错。这类错误最常见的来源是"批量选点时多框进了几个节点"。
    通用排查法：做一次零载荷、仅重力或纯热膨胀的试算——理论上应无应力自由膨胀，若算出了应力，就说明存在过约束。
  6. 习题 6（网格收敛研究与 Richardson 外推）★　用 Q4 单元计算某悬臂深梁端部挠度，三级网格结果为：8×4 → 0.173745 mm，16×8 → 0.179673 mm，32×16 → 0.181585 mm。
    (a) 用 (4.88) 反推实测收敛阶 p；
    (b) 外推出 δ∞；
    (c) 已知 Timoshenko 梁理论给出 0.182857 mm，而 48×24 网格（2 450 个自由度）算出 0.182038 mm。请比较外推值与 48×24 的直接计算值，说出你的结论。
    答案要点：(a) p = log2[(0.179673−0.173745)/(0.181585−0.179673)] = log2(0.005928/0.001912) = log2(3.100) = 1.633——接近理论值 2，略低是因为固支端存在应力奇异，污染了渐近收敛率。
    (b) δ∞ = 0.181585 + 0.001912/(21.633−1) = 0.181585 + 0.000910 = 0.182495 mm。
    (c) 相对 Timoshenko 解：外推值偏差 −0.20 %，而 48×24 的直接计算偏差 −0.45 %。结论：用三套粗网格（90 + 306 + 1 122 个自由度）做一次外推，比直接算一套 2 450 自由度的细网格更准，而且总计算量更小。这就是为什么规范要求"网格收敛研究"而不是"用尽可能细的网格"——三套粗网格的信息量大于一套细网格。
    补充思考：p = 1.633 明显低于 2，本身就是一个诊断信号，提示模型中存在奇异点或严重畸形单元。如果你在实际项目中算出 p ≈ 0.5，几乎可以肯定关键部位有尖角需要倒圆。
  7. 习题 7（编程题）★　用任意语言写一个最小的平面问题 CST 求解器（约 80 行），要求：读入节点/单元/约束/载荷，组装 K，用化 1 置 0 法施加约束，求解，输出位移、单元应力、支反力。然后：
    (a) 用例题 4-7（双向均布拉伸的四分之一模型）验证你的程序，应得到精确解 σ = (100, 100, 0) MPa——这是一次patch test；
    (b) 复现第 10.5 节的收敛表（2×1 到 32×16 六级网格），画出误差–自由度双对数曲线；
    (c) 加入绕节点平均，复现第 10.6 节跨中截面的九行数据。
    答案要点与自检靶标：① ke 的奇数列之和、偶数列之和都应是机器零（思考题 2）；② K 的秩必须是 2n − 3；③ 全部支反力之和必须等于外载合力的相反数；④ 自由节点的"反力"必须为零；⑤ patch test 必须给出机器精度的精确解，而不是"接近"——若只有 3 位有效数字吻合，说明 B 或 LM 数组有错。
    第 ⑤ 条是整份清单里最有价值的一条：常应力场是任何协调完备单元都必须精确再现的，它把"差不多对"和"真的对"区分开来。本讲义的实验台 9、实验台 10 就是这个程序的浏览器版本，可以先在实验台上对照数字，再去调自己的代码。

11.8 结语

回头看，平面问题有限元并没有引入任何新的力学——它用的还是 1 章那三组方程，还是最小势能原理，还是矩阵乘法。它做的唯一一件事，是把"求解偏微分方程"这个几乎无法下手的问题，换成"求解一个大型线性方程组"这个计算机最擅长的问题。为此付出的代价，是在两个地方引入了误差：用分片多项式近似真实位移场（离散误差，靠网格加密和高阶单元控制），以及用等效节点力近似真实分布载荷（在能量意义上其实是精确的，所以这一项不是误差，而是等价变换）。

把这本讲义的内容压成一句可以带进考场、也可以带进项目的话：

假设位移 → 求导得应变 → 能量最小 → 单元刚度 → 对号入座 → 加约束 → 解方程 → 回代求应力 → 平均并校核收敛
✓ 学完这一章之后，你应该能独立做到
① 看到一个平面构件，说出它是平面应力还是平面应变，并画出合理的网格与约束；
② 对任意分布载荷，用 (4.47) 在纸上算出等效节点力，并用合力/合力矩校核；
③ 从能量原理出发，独立推出 ke = ∫BTDBtdA，并解释它为什么对称、为什么秩亏 3；
④ 手工完成一个 2~4 单元模型的全过程，包括支反力自平衡校核；
⑤ 判断一份有限元报告是否可信——这一条最重要，也是本讲义真正想教的东西。
