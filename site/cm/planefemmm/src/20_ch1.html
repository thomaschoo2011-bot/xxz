1从杆件到连续体：平面问题是什么

1.1 上一章留下的一个漏洞

第 3 章我们处理了杆和桁架，并且反复强调了一件很舒服的事：桁架是天然离散的。杆与杆之间只在节点处铰接、只传轴力，所以"把结构切成单元"这个动作不引入任何近似——有限元解就是精确解，误差只来自舍入。

但真实的结构很少这么听话。一块开了孔的钢板、一段挡土墙、一个齿轮的轮齿、一根受内压的厚壁管，它们内部的应力是逐点连续变化的场量，没有天然的"节点"，也没有天然的"杆"。要用有限元处理它们，必须先回答一个杆件问题里根本不存在的问题：

▲ 连续体有限元的核心难题
连续体有无穷多个自由度——每一点都有自己的位移。而计算机只能解有限个未知量的方程组。 我们必须人为地把连续体切成有限个单元、只保留有限个节点位移作为未知量，并人为地规定单元内部的位移如何由节点位移插值出来。 这两个"人为"就是离散误差的全部来源，也是本章之后所有讨论（形函数、收敛准则、网格加密）的起点。

好消息是：一旦跨过这道坎，整个求解流程与第 3 章一字不差。

离散化→选位移模式→单元分析 ke→组装总刚 K→载荷等效 F→施加边界条件→解 Kd = F→回代求应力

变的只是"单元"这个词的含义：从"一根两节点的杆"变成"一小片三节点的三角形"；从 2×2 或 4×4 的单刚，变成 6×6 的单刚。矩阵变大了，逻辑没变。

1.2 降维的代价与红利：什么叫"平面问题"

一般的弹性力学问题有 3 个位移分量、6 个应变分量、6 个应力分量，未知量共 15 个。直接做三维有限元当然可以，但在教学和很多工程实践中，我们先考察一类特殊而常见的情形：所有场量都与 z 无关，且面外的力学量可以被消掉。这类问题叫平面问题，未知量缩到 2 个位移、3 个应变、3 个应力。

平面问题分两种，它们的几何图景几乎相反，数学形式却只差一组常数替换。

1.2.1 平面应力：薄板

取一块等厚薄板，厚度 t 远小于平面尺寸，所有外力都平行于板面且沿厚度均匀分布。板的上下两个表面是自由面，其上 σz = τzx = τzy = 0；由于板很薄，可以合理地认为这三个量在整个板厚范围内都近似为零：

σz = τzx = τzy = 0，　σx、σy、τxy 只是 (x, y) 的函数(4.1)
◎ 常见误解
平面应力 不是 εz = 0。板受面内拉伸时会因泊松效应变薄，εz = −ν(σx + σy)/E ≠ 0。只不过这个变薄是自由发生的，不产生 σz，因此不进入能量表达式，可以事后再算。

1.2.2 平面应变：长柱体

取一个沿 z 向非常长的柱状体（重力坝、隧道、挡土墙），横截面形状不变，外力也不随 z 变化且垂直于 z 轴。由对称性，中间任一横截面都不会沿 z 向移动、也不会翘曲：

εz = γzx = γzy = 0，　w ≡ 0(4.2)

这时 σz 并不为零——恰恰相反，正是端部的约束提供了 σz = ν(σx + σy) 才把 εz 压成零。分析时取单位厚度（t = 1）的一片来算。

1.3 平面弹性力学的三组方程

无论哪一类平面问题，未知场量都是 u(x,y)、v(x,y)，它们必须同时满足三组方程。这三组方程构成一个闭环，是后面每一步推导的依据，务必记牢。

① 平衡方程（静力学）

∂σx/∂x + ∂τxy/∂y + bx = 0，　∂τxy/∂x + ∂σy/∂y + by = 0(4.3)

其中 bx、by 是体力（单位体积的力，如自重 by = −ρg、离心力）。

② 几何方程（运动学）

εx = ∂u/∂x，　εy = ∂v/∂y，　γxy = ∂u/∂y + ∂v/∂x(4.4)

写成矩阵形式 ε = Lu，其中 L 是微分算子矩阵：

ε = εxεyγxy = ∂/∂x00∂/∂y∂/∂y∂/∂x uv (4.5)
◎ 为什么剪应变用 γ 而不用 εxy
张量剪应变 εxy = γxy/2。有限元里一律用工程剪应变 γ，因为这样应变能才能写成简洁的 U = ½εTσ——三个分量一视同仁，不用在剪切项上补系数 2。这是所有 FEM 教材的统一约定（Bathe 4.2 节称之为 "engineering notation"）。

③ 物理方程（本构关系）

各向同性线弹性材料的广义胡克定律，在平面应力下为：

σ = Dε， D平面应力 = E1 − ν2 1ν0ν10001 − ν2 (4.6)

在平面应变下为：

D平面应变 = E(1 − ν)(1 + ν)(1 − 2ν) 1ν1−ν0ν1−ν10001 − 2ν2(1 − ν) (4.7)
✓ 一个省事的技巧：两类问题的统一
把 (4.6) 中的
E → E1 − ν2　，　ν → ν1 − ν
代入，就精确地得到 (4.7)。所以程序里只需写一个 D_plane_stress(E, nu)，遇到平面应变时先把 E、ν 换掉再调用即可。 本章之后的所有推导只写 D，不区分两类问题——这正是"降维"带来的红利。

注意一个恒等式：两类问题的剪切模量完全相同。

D33 = G = E2(1 + ν)　（平面应力与平面应变一致）(4.8)

1.4 为什么非要用有限元

把 (4.3)(4.4)(4.6) 合起来消元，可以得到以位移表示的平衡方程（Navier 方程），这是一组二阶偏微分方程组。弹性力学告诉我们：对于规则区域 + 简单边界条件（半无限平面、圆孔无限板、楔形体……），可以用应力函数法求出漂亮的解析解。

但工程中真正关心的往往是：带圆角的 L 形支架、有多个螺栓孔的连接板、几何非规则的坝体截面……这些问题的边界形状就让解析法无从下手。有限元的策略是绕开"求满足所有方程的函数"，改为：

✓ 有限元的根本思路（本章的主线）
① 几何上离散：用简单形状的小单元拼出任意复杂的区域；
② 函数上离散：在每个单元内用简单的多项式插值位移，插值系数就是节点位移；
③ 方程上弱化：不再逐点满足平衡方程，而是要求总势能取驻值（等价于虚功原理），这只需要位移的一阶导数存在，对位移函数的光滑性要求大大降低。
这三步把"解偏微分方程"变成了"解代数方程组 Kd = F"。第 ③ 步是第 5 章的全部内容。
